# Slowbicycle — 게임 기획서

> slowroads.io의 "무한 절차 생성 도로 · 즉시 주행 · 몽환적 분위기 · 가벼운 UI"라는 핵심 매력을
> **자전거 라이딩**으로 재해석한 웹 게임의 기획 문서입니다.
> 본 문서는 기획 산출물이며, 실제 코드는 포함하지 않습니다.

---

## 0. 한 줄 컨셉

> **"끝없이 이어지는 시골길을, 페달을 밟으며, 해가 지는 걸 보면서 달린다."**
> 목표도 없고, 죽지도 않는다. 오직 라이딩의 리듬과 풍경만 남는다.

---

## 1. slowroads.io 핵심 매력 분석 → 자전거 재해석

| slowroads.io 핵심 매력 | 자전거 버전 재해석 |
|---|---|
| 무한 절차 생성 도로 (커브/경사가 끊김 없이 이어짐) | 동일하게 spline + 노이즈 기반 절차 생성 도로. 단, 경사(오르막/내리막)가 **속도에 실질적 물리 영향**을 주어 자전거 특유의 "오르막은 힘들고 내리막은 짜릿하다"는 체감을 살림 |
| 즉시 주행 (로딩/메뉴 없이 바로 운전) | 접속 즉시 라이딩 시작. 타이틀 화면조차 "이미 달리고 있는 배경 위에 얇은 오버레이"로 구성 |
| 몽환적 분위기 (로우폴리, 파스텔톤, 낮/밤 사이클) | 동일한 로우폴리·파스텔 톤 미학 유지 + 자전거 특유의 **페달링 리듬에 동기화된 카메라 bob**, 체인 소리 등으로 "몸으로 타는 느낌" 강화 |
| 가벼운 UI (속도/거리 외 거의 없음) | 속도(km/h) · 거리 · (선택적) 케이던스/스태미나만 표시, 무입력 시 자동 페이드아웃 |
| 실패해도 크게 벌하지 않는 톤 | 자동차보다 더 관대하게: 장애물 충돌 = "휘청임(stumble)" 애니메이션 후 자동 복귀. **게임오버 없음** |
| 차량/환경 다양성으로 반복 재미 확보 | MVP는 1개 바이옴(시골길)로 시작, 이후 로드맵에서 바이옴/자전거 종류 확장 |

---

## 2. MVP 범위 (Scope)

### 2.1 포함 (In-Scope)

- 절차적 무한 도로 생성 (커브 + 오르막/내리막), 최소 1개 바이옴: **시골길(Countryside)**
- 낮→노을→밤 시간대 순환 (스카이박스/조명 색 변화, 고정 주기)
- 자전거 물리: 페달링(가속), 브레이크(감속), 조향(좌우), 경사에 따른 속도 변화
- 3인칭 추격 카메라 (속도 연동 거리/FOV/흔들림)
- 비치명적 장애물(작은 돌/나뭇가지) — 충돌 시 휘청임 후 자동 복귀, 게임오버 없음
- 미니멀 HUD: 속도, 거리, (라이트 버전) 스태미나 바
- 타이틀 오버레이(이미 달리는 배경 위에 "라이딩 시작" 버튼) + 일시정지 메뉴(재개/재시작/설정/종료)
- 설정: 마스터/음악/효과음 볼륨, 그래픽 품질(저/중/고), 모션감소 토글
- 오디오: 앰비언트 루프 음악(낮/밤 크로스페이드), 바람/타이어/체인 SFX
- 로컬 저장(localStorage): 설정값, 최고 거리(km) 기록
- 입력: 키보드(필수), 게임패드(선택), 터치(기초 지원 — 화면 좌/우 하프탭 조향 + 하단 페달 버튼)
- 청크 스트리밍/풀링으로 무한 주행 중 메모리 안정성 확보
- 접근성 최소셋: 모션감소, 색맹 안전 팔레트, 전체 키보드 내비게이션

### 2.2 제외 (Out-of-Scope, 로드맵으로 이관)

- 멀티플레이어 / 고스트 라이더 / 리더보드(서버)
- 여러 자전거 종류·커스터마이징, 다중 바이옴(해안, 숲, 사막 등)
- 목표/미션/스토리 모드 (엔들리스 라이딩 외 목표 없음)
- 정교한 충돌·낙차 물리(라그돌 등)
- 계정/클라우드 저장, 결제/수익화 요소
- 전체 키 리매핑 UI, 자동 페달 보조 모드(접근성 심화 옵션) — 문서상 로드맵에만 명시

## 3. 핵심 게임 루프

```
[접속] → (즉시 배경 라이딩 시작, 타이틀 오버레이 표시)
   → "라이딩 시작" 클릭 또는 임의 키 입력
   → [주행 페이즈] 페달링·조향·속도 관리, 거리/시간 누적
        ├─ 장애물 충돌 → 휘청임 → 자동 복귀 (페이즈 계속)
        ├─ N km마다 은은한 마일스톤 연출 (조명/프롭 밀도 변화 + 옅은 토스트)
        └─ ESC / 일시정지 버튼 → [일시정지 메뉴] → 재개/재시작/설정/종료
   → 세션 종료 시 최고 거리 로컬 갱신
```

- **실패 상태 없음**: "죽는다"는 개념 자체가 존재하지 않음. 유일한 부정적 이벤트는 장애물 충돌에 의한 짧은 감속.
- **진행도는 장식적**: 마일스톤은 보상/해금이 아니라 분위기 변화(조명, 프롭 밀도)로만 표현 — slowroads의 "목적 없는 주행" 철학 유지.

## 4. 조작 (Controls)

| 액션 | 키보드 | 게임패드 | 터치(기초) |
|---|---|---|---|
| 페달링(가속) | `W` / `Space` (홀드) | 오른쪽 트리거(아날로그) | 화면 하단 페달 버튼(홀드) |
| 브레이크(감속) | `S` | 왼쪽 트리거 | 화면 하단 브레이크 버튼 |
| 좌/우 조향 | `A` / `D` (또는 방향키) | 왼쪽 스틱 X축 | 화면 좌/우 절반 탭&드래그 |
| 일시정지 | `Esc` | Start 버튼 | 우상단 일시정지 아이콘 |
| HUD 표시 토글 | `H` | — | — |

- 페달링은 디지털(키보드: 0 또는 1) / 아날로그(게임패드 트리거: 0~1) 모두 지원.
- 조향은 **속도에 반비례하는 회전 반경**을 가짐(고속일수록 급회전 불가) — 실제 자전거 감각 재현.
- 저속(< 2 m/s) 구간에서는 미세한 흔들림(밸런스 불안정)을 시각적으로 부여해 "멈추기 직전" 긴장감을 살림(단, 넘어지지는 않음).

## 5. 물리 모델 (Bike Physics)

단순화된 1D 종방향 동역학 + 2D 조향으로 구성. 실시간성과 예측 가능성을 위해 완전한 자전거 동역학(자이로 효과 등)은 생략.

### 5.1 종방향 힘 (속도 v, 질량 m, 경사각 θ)

```
F_pedal   = pedalInput * P_max                     // 페달링 추진력 (pedalInput: 0~1)
F_gravity = -m * g * sin(θ)                        // 오르막(+θ)에서 감속, 내리막(-θ)에서 가속
F_roll    = -Crr * m * g * cos(θ)                   // 구름 저항 (항상 속도 반대 방향)
F_drag    = -0.5 * Cd * A * rho * v^2 * sign(v)     // 공기 저항 (속도 제곱에 비례)
F_brake   = brakeInput * B_max * sign(v) * -1       // 브레이킹 (속도 역방향)

a = (F_pedal + F_gravity + F_roll + F_drag + F_brake) / m
v = clamp(v + a * dt, 0, V_MAX)   // MVP에서는 역주행 없음 (v >= 0)
```

- 기본 파라미터(튜닝 대상, 초기값): `m=80kg(라이더+자전거)`, `P_max`는 속도 0~25km/h에서 자연스러운 가속감을 주는 값으로 튜닝, `Crr≈0.005`, `Cd*A≈0.6`, `V_MAX≈45km/h`.
- **스태미나(경량 버전)**: 최대 페달 출력을 장시간 유지하면 스태미나가 감소, 페달을 늦추거나 브레이킹/코스팅 시 서서히 회복. 스태미나가 0이면 `P_max`가 일시적으로 60%로 제한(패널티일 뿐 정지되지 않음). "완급 조절"이라는 리듬감을 주기 위한 장치 — 강제성은 낮게 유지.

### 5.2 조향 (횡방향)

- 조향 입력은 목표 lean angle(기울기)로 변환되고, 이는 도로 중심 기준 횡방향 오프셋 변화율에 매핑됨.
- 최대 횡가속도는 속도에 반비례하도록 클램프하여 "고속 급회전 불가" 재현.
- 도로 폭을 벗어나면 갓길 감속(마찰 증가) 효과만 부여, 낙하/게임오버 없음.

### 5.3 충돌 & 휘청임

- 장애물(작은 돌, 나뭇가지)과 충돌 시: 짧은 감속(속도 -30~50%) + 휘청임 애니메이션(자전거/카메라 흔들림 0.4~0.6초) + 카메라 흔들림 감쇠.
- 충돌 직후 0.3초 무적(연속 충돌 방지).
- 실패 상태·라이프·게임오버 없음 — 오직 리듬이 깨지는 짧은 페널티.

## 6. 카메라

- **기본**: 3인칭 추격 카메라, 자전거 뒤 상단에서 스프링/댐핑 기반 부드러운 추적(목표 위치를 lerp/critically-damped spring으로 따라감. 급격한 컷 없음).
- **속도 연동**:
  - 카메라 거리/높이: 저속에서 가깝고 낮게, 고속에서 멀고 높게 (slowroads의 "속도감" 연출 계승).
  - FOV: 속도에 비례해 소폭 확대(예: 60°→72°)로 속도감 강화.
  - 조향 시 약간의 look-ahead(진행 방향으로 시선 선행)로 커브 예측 가능성 부여.
- **페달링 동기화 bob**: 저속(<15km/h)에서 케이던스에 맞춘 미세한 수직 흔들림 — 몸으로 페달을 밟는 느낌의 촉각적 피드백. **모션감소 옵션 활성화 시 완전히 비활성화**.
- **휘청임 흔들림**: 충돌 시 짧은 감쇠 진동 카메라 셰이크(모션감소 옵션 시 생략).

## 7. 환경 & 절차 생성

### 7.1 도로 생성

- 심플렉스/펄린 노이즈로 곡률(curvature)과 경사(elevation)를 시드 기반으로 생성, spline(Catmull-Rom 등)으로 부드럽게 연결.
- **청크 기반 스트리밍**: 플레이어 앞 일정 거리(예: 300~500m)까지 생성, 뒤로 일정 거리(예: 150m) 벗어난 청크는 폐기/풀링하여 재사용 — 무한 주행에도 메모리 상한 유지.
- 시드는 세션 시작 시 고정(재현 가능한 디버깅), 필요 시 "새로고침 = 새로운 길" 정책.

### 7.2 지형 & 바이옴 (MVP: 시골길 1종)

- 도로 양측에 노이즈 기반 낮은 언덕 지형, 인스턴싱된 로우폴리 프롭(나무, 울타리, 풀숲, 드문 가로등)을 도로에서의 거리에 따라 밀도 감쇠로 배치.
- 팔레트: 파스텔 그린/옐로우 계열 낮 → 오렌지/핑크 노을 → 인디고/네이비 밤. 각 시간대별 스카이박스 그라디언트와 조명 색온도 전환(부드러운 크로스페이드, 급격한 전환 없음).
- 안개(fog)를 원거리 컬링 은폐 + 몽환적 분위기 연출에 이중으로 활용.

### 7.3 장애물 & 마일스톤

- 장애물은 희소하게(예: km당 3~5개) 배치, 항상 회피 가능한 위치(도로 폭의 60% 이내에는 최소 1개의 안전한 통로 보장).
- N km(예: 2km)마다 은은한 시각 연출(조명 살짝 밝아짐 등) + 화면 하단에 옅게 페이드인/아웃되는 거리 토스트("2.0 km") — 알림음은 부드러운 차임벨 1회.

## 8. UI/UX

### 8.1 HUD (인게임)

- 좌하단: 속도(km/h), 우하단: 누적 거리(km). 폰트: 둥근 산세리프, 반투명 배경.
- (선택) 스태미나 바: 화면 하단 중앙에 얇은 바.
- **자동 페이드**: 60초 무입력 시 HUD가 서서히(3초) 페이드아웃되어 화면을 비움 → 사진처럼 풍경을 감상 가능. 입력 재개 시 즉시 페이드인.
- HUD 표시 여부는 `H` 키로 수동 토글도 가능.

### 8.2 타이틀 오버레이

- 별도의 정적 타이틀 화면 없음. 배경에서 이미 자전거가 프리셋 경로로 달리는 장면 위에, 반투명 오버레이로 "Slowbicycle" 로고 + "라이딩 시작" 버튼 + 설정 아이콘만 표시.
- 버튼 클릭/임의 키 입력 시 오버레이가 페이드아웃되며 실제 조작 가능한 세션으로 전환(끊김/로딩 없음).

### 8.3 일시정지 메뉴

- 항목: 계속하기 / 다시 시작 / 설정 / 타이틀로.
- 설정 패널: 마스터/음악/효과음 볼륨 슬라이더, 그래픽 품질(저/중/고), 모션감소 토글, 색맹 안전 팔레트 토글.
- 모든 메뉴는 키보드만으로 완전 내비게이션 가능(Tab/화살표 + Enter), 포커스 상태 시각적으로 명확히 표시.

## 9. 오디오

- **배경음악**: 로파이/앰비언트 성격의 루프 트랙 2종(낮용/밤용)을 시간대 전환에 맞춰 크로스페이드.
- **SFX**:
  - 바람 소리: 속도에 비례한 볼륨/피치.
  - 타이어-노면 소리: 속도 및 노면(포장/비포장 예정) 연동.
  - 체인/페달 소리: 케이던스(페달링 빈도)에 동기화된 반복 사운드.
  - 마일스톤 차임벨: 부드럽고 짧게, 방해되지 않는 톤.
  - 충돌 휘청임 사운드: 과장되지 않은 "덜컹" 사운드.
- Web Audio API 기반, 볼륨은 마스터/음악/효과음 3그룹 독립 조절. 음소거 상태에서도 플레이에 지장 없음(오디오는 순수 연출 요소).

---

## 10. 접근성 (Accessibility)

MVP 필수 항목:

1. **모션감소(Reduce Motion) 토글**: 카메라 bob, FOV 속도 연동, 충돌 셰이크를 모두 비활성화.
2. **색맹 안전 팔레트 토글**: 마일스톤/경고 등 색상 의존 신호를 색상+형태(아이콘/펄스) 이중 코딩으로 전환.
3. **전체 키보드 내비게이션**: 메뉴/설정의 모든 상호작용 요소는 Tab 순서와 포커스 표시를 갖추고 마우스 없이 조작 가능.
4. **UI 스케일 조정**: HUD/메뉴 텍스트 크기 배율(예: 100%/125%/150%) 옵션.
5. **오디오 의존 신호의 시각적 대체**: 마일스톤 차임벨 발생 시 화면에도 옅은 펄스 표시(청각 장애 사용자 배려).

로드맵(향후) 항목: 키 리매핑 UI, 원버튼(자동 페달 보조) 모드, 스크린리더 친화 라벨(ARIA) 전체 적용.

---

## 11. 성능 목표

- **프레임레이트**: 중급 통합 GPU 노트북 기준 평균 60fps 목표, 저사양 환경에서도 동적 품질 다운스케일을 통해 30fps 하한 유지.
- **초기 로드**: 광대역 환경에서 3초 이내 인터랙티브 상태 진입(에셋은 절차 생성 우선, 사전 제작 에셋 최소화 및 압축).
- **메모리**: 청크 풀링으로 5분 이상 연속 주행 시에도 메모리 사용량이 일정 범위에서 수렴(무한 누적 없음).
- **최적화 기법**:
  - 인스턴싱(프롭 반복 요소), 프러스텀 컬링, 거리 기반 LOD.
  - 오브젝트 풀링(청크, 프롭, 파티클) — GC 스파이크 방지.
  - 안개를 활용한 원거리 컬링 은폐(팝인 최소화 + 분위기 연출 겸용).
  - 그래픽 품질 프리셋(저/중/고): 드로우 디스턴스, 그림자 유무, 프롭 밀도, 안티앨리어싱 단계적 조정.

## 12. 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 렌더링 | Three.js (WebGL2) | 로우폴리 씬에 충분히 가볍고 생태계 성숙 |
| 언어 | TypeScript | 물리/절차생성 로직의 타입 안정성 |
| 빌드 도구 | Vite | 빠른 개발 서버, 가벼운 프로덕션 번들 |
| 절차 생성 | simplex-noise (또는 동등 라이브러리) | 도로 곡률/경사/프롭 밀도 노이즈 |
| 오디오 | Web Audio API (필요 시 howler.js 보조) | 크로스페이드/그룹 볼륨 제어 |
| 상태 저장 | localStorage | 설정값, 최고 거리 — 별도 백엔드 불필요 |
| 정적 배포 | 정적 호스팅 (예: Netlify/Vercel/GitHub Pages) | MVP는 서버 로직 없음 |
| 테스트 | Vitest (단위: 물리/노이즈 로직), Playwright(선택, 스모크 e2e) | |
| 품질 도구 | ESLint, Prettier | |

이 스택은 slowroads.io와 유사하게 **순수 클라이언트 사이드 정적 웹앱**으로 구현 가능하며, 서버/DB 없이 MVP 배포가 가능함을 전제로 함.

## 15. 수용 기준 (Acceptance Criteria)

MVP 완료를 판단하기 위한 검증 가능한 기준 목록:

1. **즉시 주행**: 페이지 로드 후 별도의 로딩 화면·필수 클릭 절차 없이 3초 이내에 배경에서 자전거가 절차 생성 도로를 주행 중인 화면이 표시된다.
2. **무한 도로**: 최소 5km 연속 주행 시 도로의 반복(시각적으로 동일한 패턴 재등장)이나 이음매(seam)가 관찰되지 않는다.
3. **조작 반응성**: 키보드만으로 페달링(가속)·브레이크(감속)·좌우 조향이 가능하며, 각 입력에 대해 물리적으로 합당한 방향의 속도/가속도 변화가 즉시 나타난다.
4. **경사-속도 상관**: 오르막 구간에서 동일 페달 입력 대비 속도가 감소하고, 내리막 구간에서 증가함이 로그/디버그 오버레이로 확인 가능하다(경사각 부호와 가속도 부호가 일치).
5. **비치명적 충돌**: 장애물과 충돌 시 게임오버 없이 휘청임 애니메이션 후 자동으로 정상 주행 상태로 복귀한다(라이프/재시작 개념 없음).
6. **미니멀 HUD**: HUD는 속도와 거리만 상시 표시하며, 60초간 입력이 없으면 서서히 페이드아웃되고 입력 재개 시 페이드인된다.
7. **일시정지/설정 동작**: 일시정지 메뉴에서 재개·다시 시작·볼륨 조절·그래픽 품질 변경이 정상 동작하며, 설정값은 새로고침 후에도 유지된다(localStorage).
8. **성능**: 중급 통합 GPU 노트북에서 평균 60fps를 유지하고, 인위적 부하 상황에서도 자동 품질 다운스케일을 통해 30fps 이하로 떨어지지 않는다(다운스케일 동작이 로그로 확인 가능).
9. **접근성**: 모션감소 옵션 활성화 시 카메라 bob/FOV 속도 연동/충돌 셰이크가 모두 비활성화되며, 전체 메뉴가 마우스 없이 키보드만으로 내비게이션 가능하다.
10. **오디오**: 마스터/음악/효과음 볼륨을 독립적으로 0까지 낮출 수 있고, 전체 음소거 상태에서도 게임 플레이(조작/판정)에 지장이 없다.
11. **메모리 안정성**: 5분 이상 연속 주행 시 브라우저 메모리 사용량이 발산하지 않고 일정 범위 내에서 수렴한다(청크 풀링 검증).
12. **기록 저장**: 세션 종료(타이틀로 복귀) 후 재접속 시 이전 세션의 최고 거리 기록이 표시된다.

## 16. 로드맵 (MVP 이후)

- 추가 바이옴: 해안 도로, 숲길, 사막 노을길 — 각기 다른 팔레트/프롭/사운드 세트.
- 자전거 종류 다양화(로드/그래블/픽시 등 — 물리 파라미터 프리셋 차별화).
- 날씨 시스템(옅은 비/안개 강화) 및 계절감.
- 원버튼 접근성 모드(자동 페달 보조), 키 리매핑 UI.
- 로컬 리플레이(고스트) — 자신의 이전 주행과 비교(경쟁이 아닌 관찰용).
- 사진 모드(HUD 완전 숨김 + 자유 카메라)로 몽환적 풍경 감상 강화.

## 17. 리스크 & 오픈 이슈

- **물리 파라미터 튜닝**: 실제 자전거 감각과 "가벼운 웹게임"으로서의 접근성 사이 균형은 프로토타입 플레이테스트로 반복 조정 필요.
- **터치 조작 완성도**: MVP는 기초 지원만 포함 — 모바일 최적 조작(제스처/기울기 등)은 별도 검증 필요.
- **절차 생성 시드 관리**: "새로고침마다 새로운 길" vs "동일 시드 재현" 정책은 사용자 피드백에 따라 재검토.
- **스태미나 메커닉의 강제성**: 너무 강하면 slowroads 특유의 "무목표 힐링" 톤을 해칠 수 있어, MVP에서는 패널티를 약하게(60% 출력 제한) 설정 — 플레이테스트 후 완전 제거 여부 결정.
