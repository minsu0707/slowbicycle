# slowbicycle

`slowroads.io`의 끝없는 드라이빙 감성을 자전거의 페달링, 경사, 기울기로 재해석한 브라우저 라이딩 시뮬레이션입니다.

## 실행

```bash
npm install
npm run dev
```

키보드 `W`/`Space`로 페달, `S`로 브레이크, `A`/`D` 또는 방향키로 조향합니다. `Esc`로 일시정지하고 `H`로 HUD를 숨길 수 있습니다.

## 검증

```bash
npm test
npm run build
```

상세 기획은 [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)를 참고하세요.
